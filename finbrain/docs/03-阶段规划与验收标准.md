# 03-阶段规划与验收标准

## Phase 0

- 目标：
  - 建立 `finbrain/` 和 `infra/apps/*` 的边界
  - 固化系统架构、认证基线和数据模型
- 验收：
  - `finbrain/` 与 `infra/apps/*` 目录存在
  - 文档、部署 README、代码骨架齐备

## Phase 1

- 目标：
  - Firefly III 上线
  - 最近 3 个月信用卡账单可导入
  - 建立银行卡 / 信用卡 / 理财账户体系
- 验收：
  - 未登录访问 `/firefly/` 跳转 Authelia
  - 伪造 `Remote-User` 头无法绕过认证
  - 账单导入后余额与银行对账一致
  - 2 个账期后 rule engine 自动归类率 `>= 95%`

## Phase 2

- 目标：
  - Ghostfolio 上线
  - 汇丰与富途双券商账户基线建立
- 验收：
  - `/ghostfolio/` 受 Authelia 保护
  - `HSBC HK` 和 `Futu HK` 独立展示
  - 导入脚本可写入 `/api/v1/import`

## Phase 3a

- 目标：
  - HSBC PDF source
  - review UI
  - 最小 dashboard
- 验收：
  - OCR 导入必须经过 review
  - 相同 `(source, source_ref)` 重放不重复写入

## Phase 3b

- 目标：
  - Futu CSV source
  - 异常检测与自动导入
- 验收：
  - 正常 CSV 自动进入 dispatcher
  - 异常记录进入 review 队列

## Phase 3c

- 目标：
  - HSBC 理财 source
  - `wealth_products`
  - 理财 dashboard
- 验收：
  - 理财产品可按到期日、类型、收益状态聚合
  - 仅符合条件的固收产品映射为 Ghostfolio `INTEREST`

## Phase 4

- 目标：
  - Futu OpenAPI
  - OpenD CronJob
- 验收：
  - 每日自动拉取
  - OpenAPI 不可用时 CSV fallback 可单独恢复
