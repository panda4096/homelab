# 01-整体架构与边界

## 目标

把个人财务系统拆成“账本、投资、接入、聚合”四层，避免单个应用同时承担多种不兼容的职责。

## 组件

### Firefly III

- source of truth：
  - 现金
  - 银行卡余额
  - 信用卡负债
  - 银行理财现金流
- 不负责：
  - 证券持仓价格跟踪
  - 券商收益分析

### Ghostfolio

- source of truth：
  - 证券持仓
  - 市值
  - 多券商收益分析
- 固定账户模型：
  - `HSBC HK`
  - `Futu HK`
- 不负责：
  - 银行理财主账本
  - 信用卡与银行卡现金流

### ingest-agent

- source of truth：
  - 原始导入记录
  - `source + source_ref` 去重键
  - `raw_payload`
  - review 状态
  - `wealth_products`
- 负责：
  - source adapters
  - normalizers
  - dispatchers
  - review UI
  - dashboard 聚合 API

### dashboard

- 只读聚合层
- 不成为新的 source of truth
- 每张卡片都必须可追溯到底层 Firefly、Ghostfolio 或 ingest-agent 记录

## 当前访问模型

```text
client
  -> Traefik Gateway API
  -> Authelia ForwardAuth
  -> Firefly / Ghostfolio / finbrain
```

## SSO 边界

- 当前统一认证沿用 `Authelia`
- `Firefly` 和 `finbrain` 走 forward-auth
- `Ghostfolio` 首版不依赖 experimental OIDC
- Ghostfolio 对外入口受 forward-auth 保护；应用内仍保留本地管理员账号与 API token

## 路径与仓库边界

- 产品设计与实现：
  - `finbrain/`
- 部署资产：
  - `infra/apps/firefly/`
  - `infra/apps/ghostfolio/`
  - `infra/apps/finbrain/`
