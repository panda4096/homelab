# 05-Dashboard 与聚合视图

## 首页固定区块

### 1. 顶部净资产摘要

- 原生展示：
  - HKD
  - USD
  - CNY
- 可选展示：
  - base currency 汇总
- 约束：
  - 只有配置了明确 FX 来源后才能显示折算值
  - 页面必须标注汇率来源和 `as of`

### 2. 四分类余额

- 现金
- 负债
- 证券
- 理财

### 3. 理财到期日历

- 未来 90 天
- 支持按产品类型过滤

### 4. 最近导入审计

- 最近导入批次
- 处理结果
- 去重结果
- 原始文档回溯

### 5. 异常告警与待审核任务

- OCR 置信度低
- 账户映射失败
- 金额 / 手续费超阈值
- dispatcher 写入失败

## 数据来源

- Firefly：现金、负债、理财现金流
- Ghostfolio：证券市值与收益
- ingest-agent：审计、review、wealth_products

## 设计约束

- 首页只读
- 不允许用户在 dashboard 直接修改底层账本
- 每张卡片都要能追到原始系统
